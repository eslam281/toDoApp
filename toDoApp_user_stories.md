# toDoApp User Story

Exercise 3: User Stories for Login & Registration

Application Registration: A user can register by entering their username, email, and password, and then clicking the Sign Up button.

Application Login: For the login process, users will input their email and password, and then use the Login button to access their account.

Error Feedback on Signup and Login: A user will receive a message if they attempt to click the Sign Up button without entering their details. If the user enters the incorrect username or password, they will receive a message indicating that the login attempt was unsuccessful.

Store User Data: User details will be saved in local storage so that the data persists between app sessions.

Exercise 4: User Stories for Home Screen

View Overview of Habits:
As a user, I want to view an overview of my daily habits on the home screen so that I can monitor my daily progress at a glance.

Quick Access to Habit Configuration:
As a user, I want to access the "Configure Habits" page via a plus button at the bottom right of the home screen so that I can add new habits and assign custom colors efficiently.

Manage Habits with Gestures:
As a user, I want to swipe left on a habit to mark it as completed or swipe right to return it to the to-do list so that I can manage my list with minimal clicks.

Exercise 5: User Stories for Detail / Configuration Screen

View and Customize Habit Details:
As a user, I want to view and set detailed information for a selected habit (such as its name and custom color) on the configuration screen so that I can personalize my tracking experience.

Save Habit Configurations:
As a user, I want to save my configured habit details so that they are added to my to-do list and stored securely in local storage.

View Weekly Progress Reports:
As a user, I want to view detailed progress reports on the reports screen so that I can track and evaluate how well I am maintaining my daily habits over time.

Exercise 6: Develop User Stories To Integrate Persistent Data

Persist User Login & Session State:
As a user, I want my login state and profile details to persist across app sessions so that I do not need to re-enter my credentials every time I open the app.

Persist Habit Data locally:
As a user, I want my daily habits, to-do list, and completed items to be saved in local storage so that my progress is not lost when I close the app.

Persist Personal Info and Settings:
As a user, I want my personal details (like name, username, and age) and notification preferences to be saved persistently so that my customized settings remain intact over time.

Exercise 7: Develop User Stories To Integrate External API

Integrate Real-Time Data (Habit App Context):
As a user, I want to view external data like daily motivational quotes or weather updates on the home screen so that I can stay motivated while planning my daily habit activities.

Fetch Live Updates:
As a user, I want the app to fetch real-time updates from an external API so that my dashboard displays current contextual information without requiring a manual app refresh.

Enhance App Functionality via APIs:
As a user, I want the app to integrate third-party services so that I can access advanced capabilities and dynamic features directly within the mobile interface.

Exercise 8: Develop User Stories To Implement Settings Menu

Access Menu Settings Easily:
As a user, I want to tap the three horizontal lines at the top left of the home screen to open the menu settings so that I can easily adjust my preferences and navigate to different sections.

Manage Personal Information:
As a user, I want to access the "Personal info" tab from the menu so that I can view and save my details (such as name, username, and age) which will then appear at the top of the app.

Configure Notifications and Reports:
As a user, I want to access the notifications and reports tabs from the menu so that I can enable custom habit alerts, choose when to receive them, and view my weekly habit progress.

Exercise 9: Develop User Stories To Implement Settings Screen

Configure Habit Notifications:
As a user, I want to access the notifications settings to enable reminders for selected habits and choose when I want to receive them so that I can stay on track with my daily goals.

Update Personal Profile Details:
As a user, I want to update my personal information (such as my name, username, and age) in the settings/profile section so that my current details are saved and displayed correctly across the app.

Session Management (Sign Out):
As a user, I want to sign out from the app settings so that my session is safely closed and I am returned to the login screen.

Exercise 10: Develop User Stories To Implement Notifications

Enable Habit Reminders:
As a user, I want to enable notifications for selected habits so that I receive timely reminders to complete my daily tasks.

Customize Notification Timing:
As a user, I want to choose when I want to receive my notifications so that I am alerted at the best time for my daily schedule.

Manage Notification Toggles:
As a user, I want to turn notifications on or off in the notification settings so that I stay in control of my daily habit alerts.
